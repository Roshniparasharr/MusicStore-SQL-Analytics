# SQL Project - Music Store Data Analysis
This project involves analyzing a Music Store database using a collection of SQL queries to uncover insights on customer spending, top-selling artists, and popular music genres. Through this project, we explore sales trends, genre preferences by region, and customer behavior using various SQL techniques.

# Project Overview
The main objective of this project is to use SQL queries to analyze the Music Store's database and derive meaningful insights from the data. By answering business-related questions, the project provides a deep dive into the store’s operations, including identifying the best customers, the most popular genres, and the regions that generate the most sales.

# Key Analysis Areas:
- Customer Spending Patterns: Identifying the customers who spend the most and their favorite genres.
- Artist Performance: Discovering which artists and bands have the highest number of tracks and sales.
- Regional Insights: Exploring the most popular genres and spending habits by country and city.

# Database & Tools Used
- Database: PostgreSQL (Music Store Schema)
- SQL IDE: PgAdmin4

# How to Use
- Database Setup: Load the provided Music Store schema into your PostgreSQL database.
- Run the Queries: Execute the SQL queries in PgAdmin4 or any other SQL environment.
- Explore Insights: Analyze the results to gain insights into customer behavior, top artists, and sales trends.
